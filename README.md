## Opis domene
AutoRent obuhvaća cijeli ciklus poslovanja rent-a-car servisa od evidencije voznog parka, preko upravljanja rezervacijama i servisima vozila, pa sve do financijskog aspekta kroz godišnji obračun prihoda i troškova po vozilu.

## Specifikacija projekta
AutoRent je desktop aplikacija koja digitalizira sve administrativne poslove jednog rent-a-car servisa. Aplikacija zamjenjuje tradicionalne Excel tablice koje su se do sada koristile za praćenje vozila, rezervacija i servisa.
